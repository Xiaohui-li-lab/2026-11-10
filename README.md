## Description
CCQF-PD-1.0 is a structured phenomenological dataset designed to support the study of consciousness phenomena and laws under the Chirally Coherent Quantum Framework (CCQF). It catalogues 20 consciousness-related phenomena/laws, each coded for evidence type, testability, theoretical status, and cross-domain relevance.

## Files
1. `ccqf_pd_1.0_main.csv` — Main dataset with 20 phenomena and their coded attributes.
2. `ccqf_pd_1.0_codebook.csv` — Complete codebook defining all variables and coding schemes.
3. `ccqf_pd_1.0_references.csv` — Mapping of phenomena to primary references.
4. `ccqf_pd_1.0_validation_checklist.csv` — Validation checklist for independent raters.

## Key Variables
- `Phenomenon_ID`: Unique identifier (P1–P20)
- `Category`: Ontological, epistemological, experiential, or social
- `Evidence_Type`: Experimental, observational, theoretical, phenomenological, religious/textual
- `Testability`: Direct, indirect, or to_be_tested
- `Theoretical_Status`: empirical, theoretical_conjecture, or phenomenological_hypothesis
- `Empirical_Support_Score`: 0–5 scale based on published evidence
- `Predicted_Test`: Associated testable prediction (H1–H6) if applicable

## Usage
Researchers may use this dataset to:
- Conduct meta-analyses of consciousness phenomena
- Design experiments to test specific predictions
- Compare theoretical frameworks (IIT, GWT, Orch OR, CCQF)
- Develop new phenomenological coding schemes

## Notes
- This is a theoretical/phenomenological dataset; no new experimental data were generated.
- Phenomena marked as "to_be_tested" are explicitly conjectural and require future empirical validation.
- The dataset is intended to be expanded in future versions (CCQF-PD-2.0, etc.).
